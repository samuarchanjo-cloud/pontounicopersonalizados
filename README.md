# Ponto Único Personalizados

Site institucional e catálogo digital da Ponto Único Personalizados.

## Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- React Router DOM

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

O arquivo `vercel.json` mantém as rotas da aplicação disponíveis quando acessadas diretamente na Vercel.
